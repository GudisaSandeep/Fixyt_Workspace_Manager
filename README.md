# Fixyt

> **Browsing isn't Linear anymore.**

Fixyt is a spatial browser workspace manager that turns the traditional linear tab bar into a visual, interactive 2D workspace. Instead of treating tabs as a stack of isolated pages, Fixyt lets you organize, connect, save, restore, annotate, search, and collaborate around the context of your work.

🧩 **Product:** Fixyt Workspace Manager  
🖥️ **Platform:** Chromium-based browsers  
💳 **Pro:** One-time $12 lifetime access

## Overview

Modern work happens across the browser.

A single project can involve research, documentation, GitHub issues, design files, AI tools, dashboards, communication apps, videos, spreadsheets, and dozens of reference pages. Traditional browser tabs were designed to open pages, but they were not designed to represent the relationships between those pages.

Fixyt approaches the browser as a **workspace layer**.

Instead of:

`Tab → Tab → Tab → Tab → Tab → ...`

Fixyt gives you a spatial environment where information can be arranged into visual groups, connected with workflow lines, annotated with notes, and preserved as reusable project context.

The result is a browser workflow designed around **projects, context, and relationships**, rather than tab order.

---

## Why Fixyt Exists

### The traditional tab bar breaks down under complex work

When a browser session becomes large, several problems appear:

- Important pages become visually indistinguishable.
- Related tabs are separated by unrelated tabs.
- Project context disappears when a session is closed.
- Rebuilding a working environment takes repetitive manual steps.
- Research, implementation, communication, and documentation become fragmented.
- Switching between projects becomes difficult.
- Browser work becomes increasingly dependent on memory.

Fixyt addresses this by turning browser state into a reusable and visual workspace.

### The central idea

**A browser should help you remember the structure of your work, not force you to remember the location of every tab.**

# Core Capabilities

## 1. Spatial Workspace Canvas

Fixyt replaces the linear mental model of tabs with an interactive 2D workspace.

Tabs and workspace elements can be positioned spatially, creating a visual map of a project.

You can:

- Move workspace items freely.
- Zoom and navigate a large workspace.
- Arrange related pages near each other.
- Build visual regions for different parts of a project.
- Treat browser context as a spatial system.

This makes the workspace itself part of the thinking process.

---

## 2. Save Workspace

A Fixyt workspace captures the browser environment you are working with and stores it as a reusable workspace.

Instead of reconstructing a project manually every time, you can save its context and return later.

Typical examples include:

**Engineering Workspace**

`GitHub → Documentation → Stack Overflow → Local Dev Dashboard → Deployment`

**Product Workspace**

`Research → Figma → Product Spec → Roadmap → Analytics`

**Content Workspace**

`Research → AI Assistant → Draft → Design → Publishing Dashboard`

**Study Workspace**

`Lecture → Research → Notes → AI Tutor → Assignment`

---

## 3. Restore Workspace

Saved workspaces can be reopened and reconstructed from the Fixyt environment.

The goal is simple:

> Close the project. Come back later. Continue where the context lives.

This is particularly useful for recurring projects, research sessions, client work, development environments, and long-running tasks.

---

## 4. Visual Workflow Connectors

Fixyt supports visual connectors inspired by node-based workflow interfaces.

Tabs, notes, and other workspace elements can be connected with visual paths to express relationships.

For example:

`Research → ChatGPT → Documentation → GitHub`

A connection does not merely decorate the workspace. It can communicate the structure of a workflow, dependency, or sequence.

This makes the workspace closer to a **visual project graph** than a conventional tab manager.

---

## 5. Sticky Notes, Annotations & Whiteboard

The workspace is not limited to browser pages.

Fixyt provides:

- Sticky notes
- Text annotations
- Shapes
- Stickers
- Freehand illustrations
- Visual workspace markup

This lets you place thoughts directly beside the browser context they belong to.

---

## 6. Real-Time Collaboration

Fixyt includes collaboration rooms built around the spatial workspace.

Teams can use shared rooms to:

- View the same workspace.
- Organize pages together.
- Add or edit workspace elements.
- Research collaboratively.
- Build shared visual project maps.

This turns browser research from a solitary activity into a shared working environment.

---

## 7. Spotlight Search

Fixyt includes a keyboard-driven command palette accessible with:

`Ctrl + Space`

The command center is designed for quickly finding tabs and invoking workspace actions without hunting through the browser interface.

The objective is to make large workspaces navigable through both spatial and keyboard interaction.

---

## 8. Focus & Strict Lockdown Modes

Fixyt includes focus-oriented modes designed to reduce distractions while working on a specific task.

Focus capabilities include:

- Timed focus sessions
- Fullscreen-oriented focus behavior
- Warning alerts
- Strict lockdown-style workflows

The idea is to create a temporary environment where the browser is optimized for completing the task in front of you.

---

## 9. Smart Auto-Layout

Fixyt can automatically organize and align workspace windows and elements.

Auto-layout helps transform an unstructured collection of pages into a more readable visual arrangement without requiring everything to be positioned manually.

---

## 10. Sections & Group Dragging

Workspace elements can be grouped into visual sections.

Sections can be used to separate areas such as:

- Research
- Engineering
- Design
- Planning
- Communication
- References

Grouped elements can move together, allowing a workspace to remain organized as it grows.

---

## 11. Navigation Modes

Fixyt can switch the navigation experience between:

- Individual tabs
- Workspace sections

This provides both granular navigation and high-level project navigation.

---

## 12. JSON Import & Export

Fixyt supports workspace backup and sharing through JSON.

This enables users to:

- Export a workspace.
- Keep an offline backup.
- Move workspace state between environments.
- Share a visual workspace representation.

The workspace becomes portable data rather than something trapped inside one browser session.

---

## 13. Spatial Todo Lists

Tasks can exist directly inside the workspace.

A project can therefore contain:

`Browser Tabs + Notes + Connectors + Tasks`

instead of splitting context across several unrelated productivity applications.

---

## 14. Magic Auto-Organize

Fixyt provides one-click organization designed to automatically categorize cluttered browser context into custom workspace sections.

This is useful when a session has already grown messy and the user wants to convert it into a structured project environment quickly.

## 15. Auto-Pan

The spatial workspace supports continuous edge panning while dragging elements or drawing near the edges of the viewport.

This makes large workspaces easier to manipulate without repeatedly stopping to reposition the camera.

---

## 16. Themes & Focus Soundscapes

Workspace presentation can be customized through visual themes and focus-oriented audio experiences.

The goal is to make the working environment feel intentional rather than purely utilitarian.

---

## 17. Workspace Auto-Save

Fixyt automatically persists workspace state to reduce the risk of losing changes.

The workspace is designed to behave like a persistent environment rather than a temporary collection of tabs.

# How Fixyt Works

The basic workflow is intentionally simple.

### Step 1 — Capture

Take the browser context you are already using and save it into a named Fixyt workspace.

### Step 2 — Arrange

Organize pages spatially, create sections, add notes, connect related elements, and build a visual map of the project.

### Step 3 — Reopen

Return to the workspace later and reconstruct the working environment without rebuilding the entire browser session manually.

---

# The Fixyt Mental Model

Traditional browsers organize work like this:

`Page → Tab → Window`

Fixyt expands that model:

`Workspace → Sections → Tabs → Notes → Tasks → Connections`

This difference is important.

A tab answers:

> **What page is open?**

A workspace can answer:

> **What am I working on, what belongs to it, and how does everything relate?**

# Privacy & Security

Fixyt follows a local-first product philosophy.

### Local-first starter experience

Free workspaces can be stored in browser storage and do not require a cloud account to be useful.

### Workspace state rather than private page contents

Fixyt's stated sync model focuses on workspace layout state rather than collecting the private contents of websites you open.

### No password collection

Fixyt states that it does not collect passwords or the private contents contained inside the websites you access.

### Scoped extension architecture

Fixyt uses Manifest V3 and scoped browser permissions as part of its extension architecture.

# Product Philosophy

Fixyt is built around a broader idea:

> **Browsing isn't Linear anymore.**

The web has become the primary operating environment for modern work, but browser interfaces still largely represent information as a sequence of tabs.

Fixyt explores another model:

**Spatial computing for browser work.**

The browser becomes a visual environment where the relationships between pages matter as much as the pages themselves.

Research can sit beside implementation.

Documentation can sit beside the issue it explains.

A note can sit beside the tab it refers to.

A task can sit beside the pages required to complete it.

The workspace becomes a map of intent.

---

# Why Spatial Workspaces?

Human work is rarely linear.

A developer may jump from an issue to documentation, then to code, then back to an AI conversation.

A researcher may move between papers, datasets, notes, search results, and discussions.

A founder may switch between customer conversations, product requirements, analytics, design, and engineering.

The browser flattens these relationships into one dimension.

Fixyt gives them back a second dimension.

That second dimension can represent:

- Context
- Grouping
- Relationships
- Dependencies
- Workflow
- Priority
- Project boundaries
